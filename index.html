Como as variáveis são organizadas e pesadas

Cada estrutura é representada por um vetor numérico — uma sequência de números que codifica todas as suas características. Esse vetor é dividido em quatro blocos, cada um com peso diferente:

Bloco 1 — Escala e vínculos (peso 1,5×)
Escala de atuação · Nº de organizações · Tipo de relacionamento
Peso maior porque definem a posição da estrutura no ecossistema de EA.
Bloco 2 — Estrutura institucional (peso 1,0×)
Espaço físico · Equipe · Recursos financeiros · PPP · Processos formativos
Peso padrão — indica o grau de consolidação da estrutura.
Bloco 3 — Temas transversais (peso 0,35× a 0,9×)
Clima · Agroecologia · Econ. Circular · Incidência Pol. · Comunicação · Desenv. Orgs
Peso condicional: estruturas Temáticas têm os temas pesando 0,9× (quase igual ao bloco 1). Estruturas Territoriais têm peso 0,35× — o tema é secundário. Ambos: 0,6×.
Bloco 4 — Objetivos estratégicos (peso 0,4×)
9 objetivos, cada um Sim/Não
Peso menor porque são declarações de intenção — mais sujeitas a viés de auto-atribuição nos dados cadastrais.

O que a variância mede: depois do treinamento, cada hexágono do mapa tem um "perfil médio" das estruturas que o habitam. A variância de uma dimensão é o quanto esse valor varia de hexágono para hexágono. Alta variância = aquela dimensão está separando os grupos. Baixa variância = aquela dimensão é parecida em toda a estrutura, não ajuda a distinguir.

O que é o SOM?

SOM significa Self-Organizing Map — Mapa Auto-Organizado. É uma técnica que aprende a organizar dados complexos num mapa bidimensional, colocando itens parecidos perto uns dos outros. O mapa não é desenhado por ninguém: ele emerge do próprio processo de aprendizado.

A ideia central: transformar complexidade em geografia

Cada estrutura de EA tem muitas características simultâneas — escala, temas, estrutura, objetivos. Comparar duas estruturas nesses múltiplos aspectos ao mesmo tempo é difícil para o olho humano. O SOM resolve isso criando uma "geografia" das estruturas: estruturas parecidas ficam em hexágonos vizinhos, estruturas diferentes ficam em hexágonos distantes. Diferenças complexas viram distâncias visíveis no mapa.

A estrutura matemática — em linguagem simples

1
Vetores: cada estrutura é convertida num vetor — uma lista ordenada de números. Por exemplo: [escala=5, orgs=3, relac=10, espaço=1, equipe=1, ...]. Esse vetor é o "endereço numérico" da estrutura em 23 dimensões simultâneas. Dimensões mais importantes (escala, relacionamento) recebem peso maior nesse vetor.
2
O mapa como grade de neurônios: o SOM é uma grade de hexágonos — aqui, 7×6 = 42 células. Cada célula tem seu próprio vetor interno chamado vetor de pesos, com as mesmas 23 dimensões das estruturas. No início, esses vetores são inicializados de forma distribuída (usando PCA) para cobrir bem o espaço dos dados.
3
Treinamento — encontrar o vizinho mais próximo: o algoritmo apresenta cada estrutura ao mapa repetidamente (aqui, 15.000 vezes). Para cada estrutura, encontra a célula cujo vetor interno é mais parecido — a BMU (Best Matching Unit). "Parecido" aqui significa menor distância euclidiana: √[(x₁−y₁)² + (x₂−y₂)² + ⋯ + (x₂₃−y₂₃)²].
4
Atualização com vizinhança gaussiana: quando uma célula é eleita BMU, ela e suas vizinhas ajustam seus vetores para se aproximar da estrutura apresentada. A intensidade do ajuste diminui com a distância — células próximas ajustam muito, células distantes ajustam pouco. Esse decaimento segue uma curva gaussiana (sino): h(d) = e^(−d²/2σ²), onde d é a distância no mapa e σ (sigma) é o raio de vizinhança, que diminui ao longo do treinamento.
5
Convergência: após milhares de iterações, o mapa converge: cada região se especializa em um tipo de estrutura. Células vizinhas acabam com vetores parecidos. O resultado é que a topologia dos dados originais — quem é parecido com quem — fica preservada no mapa 2D.

O que é a U-Matrix (as cores de fundo)

Após o treinamento, calculamos a U-Matrix (Unified Distance Matrix): para cada célula, medimos a distância média entre o seu vetor e os vetores de seus vizinhos imediatos. Esse valor revela a estrutura de clusters:

Valor baixo (claro)
A célula é parecida com suas vizinhas — está no interior de um cluster coeso.
Valor médio (âmbar)
Transição — a célula está numa zona de gradação entre dois grupos.
Valor alto (escuro)
A célula difere muito de suas vizinhas — está na fronteira entre clusters distintos.

As fronteiras escuras no mapa não são artificiais: emergem naturalmente do treinamento. Estruturas de lados opostos de uma fronteira são genuinamente diferentes em múltiplas dimensões simultaneamente.

Métricas de qualidade do mapa

Quantization Error (QE) = 0,43
Distância média entre cada estrutura e o vetor da sua célula BMU. Mede o quão bem o mapa representa os dados. Valores menores = melhor representação. Com dados predominantemente estimados e 53 estruturas, 0,43 é aceitável.
Topographic Error (TE) = 0,0%
Proporção de estruturas cujas duas células mais próximas não são vizinhas no mapa. TE = 0 significa que o mapa preserva perfeitamente a topologia dos dados — nenhuma estrutura foi "distorcida" na projeção 2D. Resultado excelente.

Por que SOM e não outras técnicas?

K-means agrupa bem, mas exige definir o número de clusters antes e não mostra as gradações entre grupos. PCA/t-SNE projeta em 2D, mas os eixos não têm interpretação direta. Cluster hierárquico mostra a árvore de agrupamentos, mas não o mapa contínuo.

O SOM combina as vantagens: preserva topologia (estruturas parecidas ficam próximas), revela fronteiras naturais (U-Matrix), permite explorar gradações (células de transição), e produz um mapa interpretável onde a posição tem significado. É especialmente adequado para dados mistos (numéricos + binários) como os nossos, e para conjuntos onde não queremos impor uma tipologia prévia — queremos descobri-la.
